Guía para diseñar marcos
  • Lienzo 1024 × 1024 px, PNG con transparencia.
  • Centro circular transparente de 420 px (el sistema lo alinea solo con la foto).
  • La foto del jugador queda un poco más pequeña dentro del hueco; el borde del marco la cubre.
  • Coloca alas, runas, espadas u otros detalles en los lados izquierdo y derecho, fuera del círculo.
  • El estilo Amplio es el recomendado para marcos con decoración lateral.

Creator Market

Aprueba contenido con un clic: se publica automáticamente en la página de Facebook y las métricas (vistas, me gusta, comentarios) se leen desde la API de Meta.

Configuración Facebook (obligatorio)

Page ID y token de página (no de usuario). Permisos requeridos: pages_show_list, pages_read_engagement, pages_manage_posts (+ publish_video para videos).

Conectar token (una sola vez)
  1. Graph API Explorer → elige tu app → Generate Access Token → marca pages_manage_posts, pages_read_engagement, pages_show_list.
  2. Consulta GET me/accounts → copia el access_token de la fila de tu página (token de PÁGINA, no el de usuario).
  3. Pega el Page ID y ese token abajo → Guardar token. No tendrás que volver a pegarlo salvo que revoques permisos.
Guía: error (#200) pages_manage_posts
  1. Entra a Meta for Developers → tu app.
  2. Permisos: Casos de uso / Permisos → añade pages_manage_posts, pages_read_engagement, pages_show_list.
  3. Roles: tu cuenta debe ser Administrador de la app Y de la página StudiosGamesRS.
  4. Graph API Explorer → elige tu app → Generate Access Token → marca los 3 permisos (y publish_video si hay clips).
  5. En el Explorer, consulta GET me/accounts → copia el access_token de la fila StudiosGamesRS (ese es el token de PÁGINA).
  6. Pégalo abajo y pulsa Guardar token, luego Probar token.

Modo Desarrollo: solo usuarios con rol en la app. Modo Live + otros usuarios: requiere App Review de Meta para pages_manage_posts.
